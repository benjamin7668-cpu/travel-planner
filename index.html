API 설정

Google AI Studio에서 Google 계정으로 로그인 → Create API key를 누르면 무료 키를 바로 받을 수 있어요. (카드 등록 불필요)

Claude Console에서 크레딧 충전 후 키를 만들 수 있어요.

키는 이 브라우저(localStorage)에만 저장되고, 선택한 AI 회사 외의 곳으로는 전송되지 않아요.
